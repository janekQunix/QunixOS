# Security Policy

## Supported Versions

QunixOS is currently in early development. Security updates will be provided for the latest development build.

| Version | Supported          |
| ------- | ------------------ |
| Main branch (dev) | :white_check_mark: |
| Older builds      | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in QunixOS (including our custom configurations, scripts, or default kernel setup), please report it privately.

You can report a vulnerability by:
1. Using GitHub's private vulnerability reporting feature (if enabled for this repository).
2. Contacting the maintainer directly via the email address listed on their GitHub profile.

Please include the following details in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact (e.g., privilege escalation, denial of service).
- Any suggested fixes, if applicable.

We will acknowledge your report as soon as possible and work on a fix. Thank you for helping keep QunixOS secure!
